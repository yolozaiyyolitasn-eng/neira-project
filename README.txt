ENGLISH WITH YOUR BRAIN | INGLES PARA TODOS
==============================================

VERSION ESTATICA VERDE - LECCIONES COMPLETAS

Cada leccion tiene su propio archivo HTML y contiene TODO el contenido
en la misma pagina:
- objetivo
- explicacion
- ejemplos en ingles y espanol
- vocabulario
- situaciones reales
- practica
- respuestas
- resumen
- video/recurso multimedia

No hay boton de "Siguiente" que divida la leccion.

Tecnologias:
HTML5 + CSS3 + JavaScript vanilla.

No usa Node.js, Next.js, React, Tailwind, base de datos ni backend.

VIDEOS:
Se incluyeron algunos videos de YouTube comprobados como recursos
actuales. Para temas donde no se puede garantizar un iframe estable,
la tarjeta abre una busqueda directa del tema en YouTube en lugar de
mostrar "video no disponible". Los IDs y busquedas estan en js/app.js.

DESPLIEGUE:
Sube directamente todos los archivos a GitHub y conecta el repositorio
con Vercel. No hay comando de build ni npm install.
